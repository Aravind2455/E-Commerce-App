🛍️ E-Commerce App

A modern MERN stack e-commerce web application that allows users to explore, search, and purchase products with a smooth shopping experience.
Built using React.js, Node.js, Express.js, and MongoDB.

🚀 Features

🧾 User-friendly UI for browsing and purchasing products

🔍 Product search and filtering

🛒 Add to cart and checkout system

📱 Fully responsive design

💾 Secure backend with RESTful APIs

🧠 Tech Stack
Area	Technology
Frontend	React.js, Redux, Tailwind CSS
Backend	Node.js, Express.js
Database	MongoDB
Tools	Git, GitHub, Postman, VS Code
⚙️ Setup Instructions

Clone the repository

git clone https://github.com/Aravind2455/E-Commerce-App.git


Navigate into folders

cd E-Commerce-App/frontend
npm install
npm run dev


(for frontend)

cd ../backend
npm install
npm start


(for backend)

Environment Variables
Create a .env file in the backend folder and add:

MONGO_URI=your_mongodb_connection_string
PORT=5000
